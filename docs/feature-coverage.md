# Feature coverage

This checklist follows the mobile and web reference image. **Preview verified** means the local sample app was exercised; it does not prove the connected Firebase deployment works. Sample graves, photos, and coordinates must be replaced with cemetery records before live use.

## Required production inputs

1. Firebase project settings, Email/Password Authentication, Firestore and Storage, plus deployed [Firestore rules](../firestore.rules) and [Storage rules](../storage.rules). The local emulator checks can be run with `npm ci --prefix tool/security && npm test --prefix tool/security`.
2. An initial administrator account and `users/{uid}` document with `role: admin`, created through the Firebase console or privileged backend.
3. Verified cemetery map center, grave coordinates, plot and burial inventory, memorial images, hours, guidelines, and emergency contact.
4. On-site Google Maps route checks and physical-device checks for QR scanning, camera uploads, and scheduled reminders.
